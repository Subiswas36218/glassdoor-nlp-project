# Evaluation Strategy

## Metrics

### Accuracy
Measures overall prediction correctness.

### Precision
Measures false positive control.

### Recall
Measures false negative control.

### F1-score
Balances precision and recall.

### ROC-AUC
Measures probabilistic discrimination capability.

---

# Validation Strategy

- Stratified train-test split
- Class balancing
- SMOTE oversampling
